# F1 Mathematical Ratings Engine — Autonomous Data Pipeline

Автономный движок загрузки результатов Гран-при Формулы-1 и расчёта объективных математических оценок экипажей (`Пилот + Болид/Настройки + Стратегия пит-уолла`).

## Алгоритмы расчёта
1. **Квалификация ($S_{\text{quali}}$):** экспоненциальная близость круга к математически идеальному кругу трассы ($t_{\text{ideal}}$).
2. **Гонка ($S_{\text{race}}$ — Вариант 2А):** динамическое взвешивание свободных кругов ($S_{\text{clean}}$) и полезных боевых действий ($S_{\text{combat}}$) по реальной доле контактной борьбы (от `90/10` при чистом доминировании с поула до `50/50` в плотной борьбе).
3. **Коэффициент силы соперника ($K_{\text{pace}}$ — Вариант 3А):** взвешивание каждого обгона и круга обороны по разнице чистого темпа экипажей в этот уик-энд.

## Автоматическое обновление
Workflow `.github/workflows/f1-season-autosync.yml` запускается автоматически **каждый понедельник в 06:00 UTC** (и по кнопке **Run workflow** во вкладке **Actions**), загружает новые Гран-при из открытого `Jolpica-F1 API`, пересчитывает рейтинги и сохраняет готовые JSON-архивы в `public/data/seasons/`.
